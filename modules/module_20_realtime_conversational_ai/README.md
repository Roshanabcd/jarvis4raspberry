# JARVIS OS — Module 20: Real-Time Conversational AI (`v1.0.0`)

Voice-first conversational assistant with animated holographic **ARIA** (female) and **ATLAS** (male) SVG avatars (zero static images), streaming WebSocket token delivery, voice interruption (barge-in), browser Web Speech STT/TTS, live subtitles, configurable AI provider adapters with automatic error recovery, and SQLite WAL conversation history.

## Lip-Sync Transparency
Browser-native TTS fallback uses **approximate syllable/vowel viseme timing** generated by `generate_approximate_visemes()` and is visibly labeled in both the API (`lip_sync_mode: "approximate_syllable_viseme"`) and UI. Connect an external phoneme-aligned TTS engine via the provider contract for phoneme-accurate lip synchronization.

## Quick Start
```bash
./scripts/setup.sh && ./scripts/run.sh
# Standalone Holographic UI: http://localhost:8120/conversational-ai
```
