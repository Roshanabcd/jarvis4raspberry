# Changelog — JARVIS Module 43 (`v1.0.0`)

## [1.0.0] - 2026-11-21
### Added
- Explicit-consent desktop screen capture service with X11/Wayland/PipeWire detection, window/region privacy redaction, and frame diffing.
- Real local Tesseract OCR engine with Pillow preprocessing, confidence scores, and bounding boxes.
- Configurable multimodal vision coordinator with privacy upload gate and bounded concurrency.
- Contextual error detection engine with deduplication, severity notifications, and prompt-injection defense.
- Coding agent CLI discovery (`agy`, `codex`, `gh copilot`) with hard ban on `--dangerously-skip-permissions` + real `ReferenceLocalRepairAgent`.
- 4-mode `AutoRepairEngine` with workspace boundary enforcement, unified diff generation, focused test verification, and live cancellation.
- Voice command adapter, native Linux/ARM64 telemetry collector, futuristic HUD (`/screen-guardian`), and React/TypeScript/Vite/Tailwind UI.
